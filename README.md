# 本地地图编辑器

这是一个完全本地运行的图片地图编辑器。桌面版使用 Electron，可把普通图片制作成带说明、图标和多级子地图入口的交互式地图。

## 项目目录

桌面版第一次启动时会要求选择项目存储根目录。之后新建项目会在该位置自动创建独立目录：

```text
projects/
└─ 项目名称/
   ├─ project.json
   └─ assets/
      ├─ maps/
      └─ icons/
```

地图和自定义图标分别存放在 `assets/maps/` 与 `assets/icons/` 中。

项目位置独立于程序安装目录和便携版临时解压目录。清理 Temp、升级或卸载应用不会删除项目。可通过顶部的“项目位置”更改根目录，通过“打开目录”直接查看项目文件。

## 安装与便携版

- 安装版使用向导安装，可选择当前用户或所有用户安装，并可自行选择安装目录。
- 当前用户安装的默认位置是 `%LOCALAPPDATA%\Programs\地图编辑器`。
- 所有用户安装的默认位置是 `%ProgramFiles%\地图编辑器`，通常需要管理员权限。
- 便携版会在 Temp 中解压程序。
- 项目存储位置保存在 `%APPDATA%\地图编辑器\settings.json`，不会存入 Temp。
- 更改项目位置时可以选择复制已有项目；复制不会删除原项目，也不会覆盖同名项目。

## 功能

- 上传图片作为主地图。项目名称将使用上传图片的名称。
- 添加说明或可递归进入的子地图入口。
- 拖动条目，或在属性面板精确编辑 X、Y 像素坐标。
- 设置文字、悬浮说明、图标位置和图标显示尺寸。
- 每个条目可独立设置文字字号、文字颜色、背景、边框和阴影。
- 提供卡片、简洁、纯文字和仅图标四种外观预设。
- 可编辑鼠标悬停外轮廓的颜色、透明度、宽度、线型和间距。
- 每个项目拥有独立图标栏，支持上传 PNG、JPEG、WebP 和 GIF 图标。内置部分预设 SVG 图标。
- 相同内容的自定义图标自动复用；仍被多个条目引用的图标不能直接移除。
- 更换子地图图片时，已有条目会按新旧图片尺寸比例换算坐标。
- 支持 `Ctrl+S` 保存和未保存修改提醒。
- 可导出单 HTML 查看器，地图和自定义图标会在导出时转换为 Base64。
- 可导出查看器文件夹，保留 `index.html + assets/` 的相对路径结构。
- 桌面查看器悬停时显示可配置外轮廓与悬浮说明，移动端点击后显示详情卡片。

## 使用

1. 第一次启动时选择一个长期保存项目的文件夹。
2. 点击“新建项目”并选择主地图图片。
3. 添加说明或子地图入口，在地图上拖动条目调整位置。
4. 在右侧属性面板选择预设图标，或上传当前项目专用的自定义图标。
5. 在“文字与外观”和“悬停外轮廓”区域调整条目样式。
6. 点击“保存项目”或按 `Ctrl+S`。
7. 根据用途选择“导出单 HTML”或“导出文件夹”。

直接使用浏览器打开 `index.html` 不保证使用情况。不保证在非 windows 系统下的使用情况。浏览器仅能进行基础编辑，保存 JSON 和导出单个 HTML 查看器，关闭页面后不保存记录。

不保证移动端的使用效果，因为没有经过测试。
