# 本地地图编辑器

这是一个本地地图编辑器。推荐作为 Electron 本地应用运行，也可以直接用浏览器打开 `index.html` 进行基础使用。

## 功能

- 新建项目时上传一张图片作为主地图。
- 在地图上添加说明链接或子地图入口。
- 链接支持文本、图标、图标位置、悬浮说明和坐标编辑。
- 子地图入口会创建对应子地图，可继续递归创建更细分的子地图。
- 可为子地图单独上传图片。
- 可保存项目为 JSON，之后重新打开继续编辑。
- 作为本地应用运行时，新建项目会自动保存到 `projects/` 文件夹。
- 作为本地应用运行时，后续保存会覆盖同一个项目 JSON 文件。
- 有未保存修改时关闭窗口会提示“还没有保存！确定要离开吗？”。
- 支持 `Ctrl+S` 快捷保存。
- 可导出独立只读查看器 HTML，查看器只能浏览和跳转，不能编辑。

## 本地应用运行

首次运行前安装依赖：

```bash
npm install
```

启动应用：

```bash
npm start
```

项目文件会保存到 `projects/` 文件夹。

## 使用

1. 运行本地应用，或双击打开 `index.html`。
2. 点击“新建项目”，选择主地图图片。
3. 点击“添加说明”或“添加子地图入口”。
4. 在地图上拖动链接调整位置，在右侧属性面板编辑内容。
5. 子地图入口可以点击“进入子地图”，也可以在地图上双击入口进入。
6. 点击“保存项目”或按 `Ctrl+S` 保存项目。
7. 点击“打开项目”导入之前保存的 `.json` 项目文件。
8. 点击“导出查看器”生成独立的只读 `.html` 文件。

## 说明

保存的项目文件和导出的查看器会把图片以内嵌数据的方式保存进去，因此不需要额外复制图片文件。

如果直接用浏览器打开 `index.html`，浏览器无法静默覆盖本地文件，保存会降级为下载 JSON 文件。
